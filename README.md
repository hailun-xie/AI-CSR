# AI-CSR
This repository contains the source code for an AI tool for generating climate services recipes (AI-CSR) and all the source data used for the benchmark comparison between AI and human recipes 
# Data
All data and results of this study, including case study information, human and AI recipes, as well as the raw human evaluation results are contained.
# Code
The code for the AI-CSR tool is contained in ipynb file. Users need to copy in their own api keys.
# Knowledge graph
The knowledge graph of climate services can be accessed through https://w3id.org/hacid/cs/sparql.
